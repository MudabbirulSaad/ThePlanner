# Issue Queue

Use this directory as the fresh-session work queue.

Workflow:

1. Pick exactly one issue from `issues/*.md`.
2. Start a fresh agent session.
3. Paste the full issue content as the task.
4. Keep scope to that issue only.
5. Run the validation commands listed in the issue.
6. When complete, move the issue file to `issues/done/`.

Do not start V2 work from memory. Let each issue file define the task, constraints, and validation for that session.
